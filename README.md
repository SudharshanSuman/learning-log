# learning-log

Weekly notes on what I learn in robotics and embodied AI.

**Focus:** Isaac Lab, NVIDIA Warp, ROS 2, simulation for robots that work with deformable and messy real-world objects.

## How this log works

- One file per week in `YYYY/week-NN.md`.
- Each entry answers three questions: what I learned, what surprised me, and what I'll do next.
- Every claim links to code or a result in one of my repos. No evidence, no entry.
- Template: [TEMPLATE.md](TEMPLATE.md)
